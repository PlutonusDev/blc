# Brothers Leagues Clubs

The parent site for the four Brothers Leagues Clubs in Queensland: Cairns, Innisfail, Townsville
and Ipswich. It introduces the group, shows where each club is, and hands visitors off to the
club's own site for menus, events and bookings.

Built with Next.js 16 (App Router), React 19 and Tailwind CSS v4.

## Running it

```bash
yarn dev      # http://localhost:3000
yarn build
yarn lint
```

## How it is put together

```
app/
  page.tsx              Home: hero, story, four clubs, map, what is inside, community, membership
  clubs/page.tsx        All four clubs plus the Queensland map
  clubs/[slug]/page.tsx One club: hours, venues, gallery, Google map, directions
  about/                Our story and the timeline
  community/            Grants, sport and charity work
  membership/           What it costs and what you get
  careers/              Where to apply
  contact/              Every phone number, address and map in one place
  sitemap.ts robots.ts icon.svg
components/
  site-header.tsx       Sticky nav with a clubs dropdown and a mobile sheet
  site-footer.tsx       Contact block for all four clubs
  club-card.tsx         The club card used on the home and clubs pages
  queensland-map.tsx    Hand built SVG map of Queensland with the four clubs pinned
  ui.tsx brand.tsx      Layout primitives, buttons, headings, monogram and wordmark
  structured-data.tsx   Organization and per club JSON-LD
lib/
  clubs.ts              Single source of truth for all four clubs
  site.ts               Site name, description and production URL
public/img/             Photography, grouped by club
```

## Editing content

Almost everything lives in [`lib/clubs.ts`](lib/clubs.ts). Addresses, phone numbers, trading hours,
venues, highlights, membership pricing, map coordinates, wayfinding colour and image references are
all defined there, and every page reads from it. Change a phone number once and it updates in the
header, the footer, the club page, the contact page and the JSON-LD.

Set the production domain in [`lib/site.ts`](lib/site.ts). It feeds canonical URLs, Open Graph tags,
`sitemap.xml` and `robots.txt`.

## Photography

Sources in `public/img/` are capped at 2400px on the long edge for full bleed images and 1600px for
everything else, re-encoded at quality 82. Keep new photography within those bounds. The originals
off the club sites ran to 4032x3024 and 3MB, which was heavy enough that the image optimizer would
intermittently fail to serve them in development.

## Share images and SEO

Per page metadata is built by [`lib/metadata.ts`](lib/metadata.ts), which writes the canonical, the
Open Graph block and a `summary_large_image` Twitter card from one call, so nothing is left to
inherit by accident. Site wide defaults, robots directives and the theme colour live in
[`app/layout.tsx`](app/layout.tsx).

The cards themselves are generated by [`scripts/generate-og.py`](scripts/generate-og.py):

```bash
python scripts/generate-og.py
```

It writes `app/opengraph-image.png` and `app/twitter-image.png` for the site, `public/og/<slug>.png`
for each club, and `app/apple-icon.png`. Club details are read straight out of `lib/clubs.ts`, so
re-run it after changing a club's name, tagline, region, address, accent or hero image. Fonts come
from Google Fonts on first run and are cached in `node_modules/.cache/og-fonts`.

JSON-LD ships alongside: an `Organization` with all four clubs on the home page, and a
`BarOrPub` plus `BreadcrumbList` on each club page.

## Maps

Two kinds. The illustrated Queensland map in `components/queensland-map.tsx` is drawn from a
simplified boundary and projected with the same function used to place the pins, so pins always land
inside the outline. Move a club and the pin moves with it. The per club maps on the club and contact
pages are Google Maps embeds keyed off the address, so they need no API key.

  the club websites and those change.
- Photography in `public/img/` was pulled from the four club sites. Confirm the group holds the
  rights to reuse it here.
- Add each club's social links if the group wants them in the footer.
